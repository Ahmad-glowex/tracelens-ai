How It Works

      
From Terminal Crash to Fixed Branch

    


    

      

        Step 01
        
Crash Slicing & Parsing

        

          The client parses raw ANSI codes, filters out irrelevant runtime boilerplates, and isolates culprit frames using language-specific heuristics.
        

      


      

        Step 02
        
Sub-Second LLM Synthesis

        

          Your configured model (Groq, OpenRouter, Gemini, or OpenAI) processes the isolated context to construct a syntactically correct fix without hallucinations.
        

      


      

        Step 03
        
Unified Git Patch Emit

        

          Outputs standard Git unified diff formatting with line offsets, ready for instant application with git apply.
